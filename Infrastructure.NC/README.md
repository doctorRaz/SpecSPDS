# Infrastructure.NC

Реализация инфраструктурных сервисов для nanoCAD. Сборка адаптирует API хоста к контрактам из проекта `Abstractions`.

## Состав

- **DocumentService** — предоставляет сведения об активном документе: полный путь, имя файла с расширением, имя без расширения и признак активности. При запросе пути без активного документа выбрасывает `NullReferenceException`.
- **CadWindowProvider** — получает и кэширует дескриптор главного окна текущего процесса через `Process.GetCurrentProcess().MainWindowHandle`.
- **CadWindowProvider_Cad** — альтернативный провайдер, получающий дескриптор через `HostMgd.ApplicationServices.Application.MainWindow`; в коде отмечен как неиспользуемый.
- **CommandLineMessageService** — выводит сообщения в командную строку активного документа; при отсутствии доступного редактора использует уведомление McNotificator, а при ошибке этого способа — диалог хоста. В конфигурации `TEST` выводит сообщения в консоль.
- **McNotificatorMessageServise** — адаптер интерфейса уведомлений к McNotificator; предоставляет методы для предупреждений, ошибок и информационных уведомлений.

## Границы и зависимости

- Основное приложение должно зависеть от контрактов `Abstractions`, а не от конкретных реализаций из `Infrastructure.NC`.
- Сборка зависит от `Abstractions`, `MulticadInterop` и пакета `nanoCAD.Platform.NET`.
- Условная компиляция `TEST` позволяет использовать тестовые реализации поведения без обращения к API nanoCAD. Это не меняет контракты публичных интерфейсов.
- XML-комментарии описывают публичные типы и члены; рабочая логика и сигнатуры при обновлении документации не меняются.
