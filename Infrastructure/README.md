# Infrastructure

Сборка `Infrastructure` содержит реализации инфраструктурных интерфейсов, объявленных в `Abstractions`. Прикладной код должен зависеть от контрактов из `Abstractions`, а не от конкретных реализаций этой сборки.

## Основные компоненты

- **`AddOnInfo`** — сведения о сборке аддона: имя и версии, атрибуты сборки, метаданные, каталоги данных и расположение пакета.
- **`AssemblyMetadata`** — чтение атрибутов `AssemblyMetadata` с поиском ключей без учёта регистра.
- **`AddOnInfoRegistry`** — потокобезопасный реестр сведений о сборках. Данные хранятся в статическом словаре и общие для экземпляров реестра в пределах процесса.
- **`AddOnInfoProvider`** — упрощённый статический доступ к получению и регистрации сведений о сборке.
- **`CadInfo`** — сведения о CAD-процессе: исполняемый файл, версии продукта и файла, разрядность и данные версии файла.
- **`SysInfo`** — сведения об операционной системе и аппаратном обеспечении. Часть аппаратных данных запрашивается через WMI.
- **`MessageService`** — выбирает вывод обычных сообщений в командную строку или окно в зависимости от активности CAD-документа; интерактивные запросы направляет оконной реализации.
- **`WindowMessageService`** — показывает оконные сообщения и диалоги, по возможности привязывая их к окну CAD-хоста.

## Примечания

- Публичный контракт инфраструктурных компонентов определяется интерфейсами из `Abstractions`.
- При недоступности некоторых сведений о CAD-хосте или ОС реализации могут возвращать значения по умолчанию; признак `IsFallback` позволяет определить fallback-режим для `CadInfo` и `SysInfo`.
- `AddOnInfo.IsNotNetworkPath` отражает результат проверки, подтверждено ли локальное расположение сборки. Неопределённое расположение не считается подтверждённо локальным.
- `AddOnInfo.PackageDirectory` использует каталог пакета только при подтверждённом расположении аддона в каталоге продукта; в остальных случаях используется каталог сборки.

XML-комментарии публичных типов и членов предназначены для описания фактического поведения API и формирования документации сборки.
