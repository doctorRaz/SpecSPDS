# SpecSPDS

[Описание проекта](https://deepwiki.com/doctorRaz/SpecSPDS) [![Ask DeepWiki](https://deepwiki.com/badge.svg)](https://deepwiki.com/doctorRaz/SpecSPDS)

Краткое описание
----------------
SpecSPDS — коллекция спецификаций и свойств для мульти-CAD (спецификация для nanoCAD). Проект объединяет описания свойств от универсального маркера до таблиц McTable, предназначенные для стандартизации обмена и хранения данных в чертежах.

Особенности
----------
- Набор стандартизованных свойств для различных объектов чертежа.
- Совместимость и рекомендации для использования в nanoCAD.
- Форматы и примеры для автоматического экспорта/импорта данных.
- Документация и примеры применения (ссылка на DeepWiki).

Требования
---------
- nanoCAD (версия, совместимая с используемыми форматами свойств).
- Прочие инструменты для конвертации/обработки (если требуется) — в зависимости от сценариев интеграции.

Установка и подключение
-----------------------
1. Склонируйте репозиторий:
   git clone https://github.com/doctorRaz/SpecSPDS.git
2. Откройте необходимые файлы спецификаций и примеры в nanoCAD или в инструменте, поддерживающем работу с атрибутами/свойствами.
3. Следуйте инструкциям в примерах для импорта свойств в шаблоны и библиотеки.

Примеры использования
---------------------
- Применение универсального маркера для обозначения точек контроля на чертеже.
- Создание и заполнение McTable из набора свойств объектов для передачи в спецификации.
- Экспорт свойств в табличный формат для обработки во внешних системах.

Структура репозитория
