# Abstractions

Модуль `Abstractions` содержит контракты, общие для компонентов SpecSPDS: интерфейсы, перечисления и ключи метаданных, необходимые для взаимодействия между слоями приложения.

Проект предназначен для `.NET Standard 2.0`, чтобы его контракты могли использоваться разными проектами решения.

## Состав

- **Infrastructure** — общие ключи и соглашения инфраструктурного уровня.
- **Services** — контракты сервисов и связанные типы, в том числе логирование и пользовательские сообщения.
- **Settings** — контракты настроек и политики проверки обновлений.

Конкретные реализации сервисов находятся в других модулях.

## Правила использования

- Зависите от интерфейсов и типов этого модуля, а не от конкретных реализаций сервисов.
- Реализуйте контракты в соответствующем модуле приложения или интеграции с хостом.
- Передавайте необходимые сервисы через конструкторы и используйте существующий механизм внедрения зависимостей в точке композиции приложения.
- Не добавляйте сюда код, зависящий от конкретного CAD-хоста, пользовательского интерфейса или инфраструктурной реализации.
- Изменения публичных контрактов согласовывайте с их потребителями: изменение сигнатур или семантики может затронуть несколько проектов.

## Документация

Публичные типы и члены документируются XML-комментариями в исходном коде. Этот README описывает назначение и границы модуля и не заменяет документацию отдельных API.
